●Рендер кликов●

Загружаете макрос уровня → назначаете звуки кликов для P1/P2 → получаете готовый mp3/wav с кликботом для записи левела.

1
Макрос
Поддерживаются: GDReplayFormat 2 (.gdr2, бинарный), GDReplayFormat 1 (.gdr, MessagePack) и JSON-макросы (frame+p1/p2, player+down и т.п.). Формат определяется автоматически по содержимому файла, а не по расширению.
Нажмите, чтобы выбрать файл макроса

Звуки кликов
Загрузите свои сэмплы для каждой категории (можно несколько — для рандомизации, как в ZCB). Если ничего не загружено — используется синтезированный клик.
Импортировать клик-пак ClickpackDB (.zip)
Сам разложит сэмплы по категориям — hard/soft/microclick → нажатия, release → отпускания, player1/player2 — по игрокам (если папок player нет, звуки достанутся обоим)
